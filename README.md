# Zapier Webhook for Google Tag Manager

A Google Tag Manager custom template for sending custom field and value pairs to a Zapier webhook.

## Features

- Send data to a Zapier webhook from Google Tag Manager
- Add multiple custom fields dynamically
- Supports GTM variables in field names and values
- Automatically URL-encodes field names and values
- Sends data using a GET request
- Simple configuration through the GTM template UI
